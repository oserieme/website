# Ebhomien Oserieme | Personal Resume Website

A personal resume website built with HTML and CSS to showcase my technical skills, projects, education, and professional experience.

## Live Website

[View My Resume](https://oserieme.github.io/website/)

## About the Project

This project is a simple, responsive personal resume website designed to provide an accessible online version of my professional resume.

It highlights my background in Computer Science, interest in Cloud Computing and DevOps, technical skills, and hands-on projects.

## Built With

- **HTML5** – Structure and content
- **CSS3** – Styling, layout, and responsive design

## Features

- Clean and professional resume layout
- Responsive design for different screen sizes
- Professional summary and technical skills
- Education and industrial training experience
- Project portfolio section
- Print-friendly styling

## Project Structure

```text
website/
```

## Getting Started

To view the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/oserieme/website.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

## Deployment

The website is hosted using **GitHub Pages**.
